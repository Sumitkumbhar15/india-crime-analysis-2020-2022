# IPC Crime Analysis in India (2020–2022)

## About the Project
- This project focuses on analyzing IPC cognizable crime data across Indian States and Union Territories for the years 2020 to 2022. 
- The objective is to study crime patterns, compare regions using crime rates, and understand whether crime levels have increased or decreased over time.

- The project is intended as a foundational data analysis exercise using Python and real government data.

---

## Dataset Information
The dataset contains state-wise and UT-wise crime statistics, including:
- Total IPC crimes for 2020, 2021, and 2022
- Mid-year projected population for 2022
- Crime rate per lakh population (2022)
- Chargesheeting rate as an indicator of investigation efficiency

The data is provided in CSV format.

---

## Tools and Technologies
- Python  
- Pandas  
- Jupyter Notebook  

---

## Work Done in This Project

### Data Preparation
- Cleaned column names for readability
- Removed aggregate rows such as total states, total UTs, and all-India totals

---

### Exploratory Data Analysis
- Analyzed crime rate distribution to compare regions fairly
- Studied chargesheeting rate distribution to observe variation in police efficiency

---

### Crime Comparison (2022)
- Identified states and UTs with the highest total number of crimes
- Compared regions using crime rate per lakh population instead of raw counts

---

### Crime Trend Analysis (2020 to 2022)
- Calculated percentage change in crime between 2020 and 2022
- Classified states as showing an increase or decrease in crime
- Visualized states with the most significant rise and decline in crime

---

## Key Observations
- Crime rate provides a more meaningful comparison than total crime count
- Some states show a noticeable increase in crime over the three-year period
- A few states demonstrate a reduction in crime, indicating improvement
- Chargesheeting rates vary significantly across regions
- The overall national trend shows a decline in reported crimes after 2020
